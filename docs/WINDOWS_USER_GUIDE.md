# Windows user guide

## Run

1. Download and unzip `DDLCard-Windows-x64.zip`.
2. Run `DDLCard.exe`. Windows may show a SmartScreen warning because the open-source build is not code-signed.
3. The task manager and the desktop card open together. Closing the manager keeps DDLCard in the system tray.

## Everyday use

- Press `Ctrl+Alt+D` anywhere to open quick add.
- Resize the desktop card to change how many deadlines it shows.
- Drag the card against the left or right screen edge and enable edge collapse in Settings.
- Use **Complete** for a quick finish or **Postpone** for one hour, tomorrow at 09:00, or next week at 09:00.
- The card is normally covered by other applications. Enable **Always on top** only when needed.

## Data and privacy

All data is stored under `%LOCALAPPDATA%\DDLCard`. DDLCard has no account, analytics, server, or automatic sync.

- **Preset code:** appearance and reminder defaults only; safe for sharing.
- **JSON backup:** includes tasks, notes and settings; treat it as personal data.

Use **Export backup** before reinstalling Windows. Import previews the task count and asks before replacing local data.
